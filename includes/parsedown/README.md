# Parsedown 1.8.0

Vendored copy of [Parsedown](https://github.com/erusev/parsedown) 1.8.0
(Emanuil Rusev, MIT). Single-class Markdown-to-HTML parser.

- Source: `https://github.com/erusev/parsedown/tree/1.8.0`
- License: `LICENSE.txt` in this directory

Do not edit `Parsedown.php` except to replace it with a newer upstream tag.
Callers that need untrusted input escaped should set `setSafeMode(true)` and
`setMarkupEscaped(true)` on the instance.
